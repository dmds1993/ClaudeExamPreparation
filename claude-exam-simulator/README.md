# Claude Architect Practice Lab

Private, local study application for the Claude Certified Architect - Foundations exam.

## Open it

Open `dist/index.html` in a modern browser. The application has no server dependency, external analytics, account, or cloud storage. Answers and attempt history stay in that browser's `localStorage`.

## Included

- 60-question, 120-minute coach-reviewed certification simulation
- all 395 purchased-course questions across six complete source sets:
  - Practice Exam 1: 65
  - Practice Exam 2: 60
  - Practice Exam 3: 65
  - Practice Exam 4: 65
  - Bonus Scenarios Set 1: 70
  - Bonus Scenarios Set 2: 70
- deterministic question shuffle with no duplicates
- single-answer and choose-two questions
- question navigator, review flags, confidence scoring, pause/resume, and autosave
- results with domain accuracy and high-confidence mistakes
- answer review in Topic -> Why -> Reason -> Example format
- Weakness Lab updated from the 843/1000 Bonus Set 2 result and the feedback review
- 15 current-documentation repair questions across six clusters, with randomized 10-question mixed drills
- corrected replacements for outdated or ambiguous course items covering sensitive-file permissions, date schemas, SDK tool loops, and subagent invocation
- dark and light themes plus responsive keyboard-accessible controls

## Answer-key status

Question stems and choices came from the purchased Udemy practice course. The source attempts were left paused and unsubmitted. The original 60-question simulation uses independently coach-reviewed keys and explanations; the six complete imported source sets are clearly labeled as completion-based until their answer keys are verified. Imported challenge questions never affect the verified score.
